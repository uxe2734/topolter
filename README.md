# 💬 Topolter Messenger

A real-time lightweight PHP chat system with file sharing, encryption, and a modern UI.

---

## 🚀 About the Project

Topolter Messenger is a simple but powerful chat application built with **PHP, MySQL, JavaScript, HTML & CSS**.

It supports real-time messaging, file sharing, unread message tracking, and encrypted storage for messages.

This project is designed as a learning + production-ready base for building scalable messaging systems.

---

## ✨ Features

- 💬 Real-time chat system (AJAX-based)
- 👥 User-to-user private messaging
- 📎 File sharing (images, videos, audio, documents)
- 🔐 AES-256 message encryption
- 👁️ Unread message tracking per user
- 🗑️ Message deletion (sender-only control)
- 🔎 User search system
- 📱 Fully responsive UI (mobile + desktop)
- ⬇️ Auto-scroll + scroll-to-bottom button
- 🔔 Browser notifications for new messages
- ⚡ Lightweight and fast (no frameworks)

---

## 🧠 Tech Stack

- PHP (Backend)
- MySQL (Database)
- Vanilla JavaScript (Frontend logic)
- HTML5 / CSS3
- AJAX (Fetch API)
- OpenSSL (Encryption)
